# Security policy

## Supported scope

This repository contains generalized documentation and a read-only inventory script. It does not operate a public service or accept real infrastructure configuration.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting feature when available. If private reporting is unavailable, contact the repository owner through GitHub without including the sensitive value in a public issue.

Do not publish credentials, tokens, private keys, addresses, hostnames, serial numbers, customer information, or unredacted command output in an issue, discussion, pull request, or commit.

Please include only:

- the affected repository path;
- the type and potential impact of the issue;
- safe reproduction steps using invented values;
- a suggested remediation, if known.

## Sensitive-data response

If sensitive information is found, do not repeat or quote it. The repository owner should revoke or rotate the affected credential first, remove the data from public access, assess exposure, and then clean repository history using an appropriate reviewed procedure.

## Safe-use notice

Review every script before execution and run it only on systems you own or are explicitly authorized to assess. Generated reports still require human review before publication.
